# JUSTITIAN: 300 Plot Hooks — Foundry VTT module

A Foundry VTT module presenting the community fanwork **"JUSTITIAN: 300 Plot Hooks"**
(by **Obie_Decker & Kleffe**) for the **DEGENESIS: Rebirth** system as four rollable tables —
one per chapter of the original PDF.

## What's inside

| Roll table | Chapter subtitle | Hooks |
|---|---|---|
| A Day in the City | Encounters with People of the Protectorate | pages 08–17 |
| Conflicts Innumerable | The Struggles that Permeate Life | pages 18–29 |
| Lands of Ruin | Discord Brewing Beneath | pages 30–41 |
| Justitian Burns | The Plots of Giants, the Ancient War, the End Times | pages 42–51 |

Each table entry contains the hook text verbatim, its ▶ addendum lines, and the
original book cross-references (e.g. `[TRF 212] • [MOL 75]`).

## Install / use

1. Copy (or symlink) this folder into your Foundry `Data/modules/` directory.
2. Enable **JUSTITIAN: 300 Plot Hooks** in your world (requires the
   **DEGENESIS: Rebirth** system, v0.8 tested on Foundry v14).
3. Open the compendium **Justitian: 300 Plot Hooks**, unlock the tables, roll.
